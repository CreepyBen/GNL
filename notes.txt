loop exit conditions

1. \n found -> slice and return the line
2. read() return 0 and leftover -> return the content as the final line
3. read() return 0 and leftover empty -> return NULL

#Helper_Functions

1. Find \n - given a string, return its position (or signal “not found”)
2. Join - given two strings, allocate new memory, copy both into it, return the new string
3. Slice\extract - given a string and a cut position, produce the “before” part (the line) 
and the “after” part (new leftover) - this might even be two separate small jobs

## FLOW ##


read -> Join (check for \n) -> Slice -> return


============

BEFORE call 1:
  leftover (old) = ""

┌─────────────────────────────────────────────┐
│ STEP 1: read() returns "Hello\nWorld\nFoo"   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ STEP 2: JOIN                                 │
│   joined = old_leftover + new_data           │
│   joined = "" + "Hello\nWorld\nFoo"          │
│          = "Hello\nWorld\nFoo"               │
│                                               │
│   ✅ FREE old_leftover ("") now — done with it│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ STEP 3: SLICE joined at first \n             │
│   line     = "Hello\n"     ← left part       │
│   leftover(new) = "World\nFoo"  ← right part │
│                                               │
│   ✅ FREE joined ("Hello\nWorld\nFoo") now —  │
│      both pieces already extracted from it   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ STEP 4: return                               │
│   return line ("Hello\n")                    │
│     ❌ do NOT free — caller owns this now     │
│                                               │
│   leftover(new) ("World\nFoo") stays in the  │
│   static variable                            │
│     ❌ do NOT free — needed for next call     │
└─────────────────────────────────────────────┘

AFTER call 1:
  static leftover = "World\nFoo"   (alive, saved)
  caller holds     = "Hello\n"     (alive, caller's job to free later)
  old_leftover ("") and joined ("Hello\nWorld\nFoo") → both freed, gone


---------------------------------------------------------------------------

loop:
  check leftover for \n
    → found? break out of loop
    → not found? read() + join, then loop again
      (unless read() hits EOF — then handle end-of-file case)

after loop:
  slice, return

File Descriptors

fd = a number the process can use to refer to something the OS has opened for it

read(fd,buff,size)

fd      → WHICH open resource?
buffer  → WHERE should the bytes go?
10      → HOW MANY bytes are we asking for?

===========
why is a persistent (static) variable required?
Because read() can only move forward through the file, never backward — so any bytes you read but 
don't immediately use must be saved somewhere, or they're lost/skipped forever. Since globals are banned, 
static is the only tool that lets a variable survive between separate calls to the same function.
